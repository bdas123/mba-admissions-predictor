How the model was built, and where it can mislead you

This page documents every data source, modeling choice, evaluation result and known weakness. Numbers marked as live are read from the same data/model.json file the explorer uses, so the page and the app cannot disagree.

Bottom line: GMAT, GPA, experience, round and school context explain part of the outcome. Cross-validated AUC is –, compared with – using school context alone. Most of the outcome depends on what the data can’t see: essays, recommendations, interviews, career story and fit. Treat each result as a range, not a verdict.

How to use it

  1. Paste a sentence about yourself and select Interpret my profile. The interpreter uses transparent pattern rules that run in your browser and send nothing anywhere. It reads GMAT (scores ending in 0 are treated as GMAT Classic and converted with the GMAC concordance), GPA, years of experience, industry, round, home state and US/non-US status.
  2. Adjust the sliders directly. Every chart updates immediately.
  3. Use the dropdown to add schools from the 2026 U.S. News top 25 (26 schools, because of a tie at #25), plus Rice Jones and Stevens Institute of Technology. Remove any school with its button.
  4. Read each card: the large number is the median of the distribution, and the highlighted bar is the bin containing it.

Data

Applicant outcomes

Applicant outcomes come from public, self-reported profiles in the GMAT Club Decision Tracker. Each profile can include a GMAT score, GPA, years of experience, industry, country, application round and outcomes (admitted, denied, waitlisted, and scholarship as a share of tuition) for several schools. The pipeline read these pages through Perplexity’s content-fetch API and did not bypass bot protection or registration walls.

Only structured profile fields are kept. Usernames, comments and free text are discarded during parsing. No row-level data is published in this repository; only model parameters and aggregate statistics appear here. The pipeline/ folder lets anyone rebuild the dataset.

The training set contains – final decisions from – applicants across – US full-time MBA programs. The cycles cover classes entering 2023–2026: –. A decision counts only when its final status is admitted or denied; waitlists without a resolution are excluded. GRE-only and test-waiver profiles are also excluded because the model is GMAT-based.

School and cycle context

For each school and cycle, the model uses applications received, the acceptance rate and the class GMAT average from Poets&Quants’ 2026 acceptance-rate and application tables. Class GMAT Classic averages were converted to Focus-equivalent values with the GMAC concordance. The class entering in 2026 uses the latest published 2025 cycle as a proxy, and the training data flags that substitution. Rankings come from the 2026 U.S. News Best Business Schools list, as compiled by Clear Admit.

Tuition and official aid figures

Tuition and official aid figures come from each school’s own pages, linked on every card. When a school publishes aggregate scholarship figures, such as Rice or McCombs, the model is calibrated to them. Dollar values are the predicted share of tuition × that school’s annual tuition × 2 years.

Admission model

The admission model is an L2-regularized logistic regression pooled across all programs. Pooling lets schools with few reports borrow strength from the rest of the data, and the school-cycle features carry selectivity. Its features are:

  • GMAT Focus relative to that school’s class reference, per 10 points
  • GPA, per 0.1, plus an indicator for a missing GPA
  • Years of experience and its square, since “too junior” and “too senior” both hurt
  • Round 1 or Round 3+
  • Non-US status
  • Industry group
  • The school’s logit acceptance rate that cycle
  • The log of the school’s applications that cycle

Correcting self-report bias

Admits post more often than denied applicants, so the tracker’s raw admit rate is –, far above real acceptance rates. The model applies King & Zeng prior correction for each school: it shifts the intercept by logit(official rate) − logit(sample rate). That correction is exact if posting depends only on the outcome. Schools with few reports are pulled toward the pooled correction with weight n/(n+50); without that, Rice, whose sample contains only admits, would receive an extreme penalty.

Why it shows a distribution

The model was refit 300 times on bootstrap resamples of applicants, so one applicant’s several schools are resampled together. Each refit produces one probability for you, and the histogram shows all 300. A wide histogram means the data can’t pin your chance down.

The spread reflects model uncertainty only. Even a 40% chance means a single application is either admitted or not.

GMAT effects look modest because the sample is range-restricted: most people who post profiles already score near each school’s class average. The odds ratio describes the marginal effect within that range, not the effect of a far-below-median score. The application-volume coefficient is mostly a between-school effect, because the largest programs are also the most selective beyond their acceptance rates. Use the volume slider as a rough sensitivity check, not a causal lever.

Extracurriculars

The project brief asked for extracurriculars to be factored in. The tracker has no structured extracurricular field, only optional notes. I tested keyword flags for volunteering, leadership, military service, entrepreneurship and athletics. Adding them left cross-validated AUC unchanged (– with them, compared with – without), and some signs were implausible. That pattern suggests the flags capture who writes long posts, not real extracurricular strength. They are therefore excluded from the score. The interpreter still lists any extracurriculars it finds, because they matter in real admissions through essays and interviews.

Scholarship model (conditional on admission)

The scholarship estimate uses two parts, both fit on admitted applicants at merit-aid schools. Stanford GSB and Harvard are excluded because their fellowships depend on financial need, not stats.

  1. P(any award): a logistic regression.
  2. The award as a share of tuition, given an award: a ridge regression on the logit of the share, with residual noise.

Each of the 300 bootstrap refits produces 10 simulated outcomes, and the histogram shows the share of simulations in each tuition band.

Self-reported awards skew high, so each school’s offsets are solved to reproduce official aggregates when the school publishes them: Rice reports that 96% receive an award, with an average above $40k; McCombs reports that 88% receive an offer, averaging $19,080. Without official figures, the offsets reproduce the tracker sample’s own means, and the card says that estimate likely runs high.

Honest assessment: stats predict whether you get an award moderately well. They predict how large the award will be barely better than simply guessing the median. The scholarship distribution is mostly driven by the school, with a modest stats adjustment; negotiation, competing offers and fellowships aren’t visible in the data.

Stevens Institute of Technology

Stevens (U.S. News 2026 #72, tie) was added on request. It has no tracker decisions, so its card uses the pooled model with the pooled self-report correction, the same treatment as Georgia Terry. Its school context comes from the Poets&Quants top-100 tables (P&Q rank #77): 687 applications and 384 admits for the class entering 2025 (55.9%), compared with 436 and 147 (33.7%) in 2024 and 516 and 193 (37.4%) in 2023.

Neither Stevens nor P&Q publishes a class GMAT, so the reference uses a third-party GMAT Classic average of 594 from CampusReel, converted to Focus 555. BeatTheGMAT lists 570; using it would raise the estimate slightly. Stevens's acceptance rate is far above every other school in the app, so the logistic model is extrapolating there. Treat the Stevens estimate as a rough range rather than a calibrated probability.

The scholarship isn't modeled. Stevens's graduate financing FAQ describes merit awards for first-year, full-time, on-campus master's students, disclosed at admission, plus a $4,000 supplement, but publishes no award rates or averages. Tuition uses the 2026–27 graduate full-time rate of $22,995 per semester.

Known limitations

  • Selection bias: people who post profiles differ from typical applicants. The bias correction handles outcome-driven posting, but not posting driven by profile strength.
  • Missing information: the data contains nothing about essays, recommendations, interviews, career goals, diversity factors, legacy status or employer brand.
  • Self-reported values: fields are unverified, and the parser can occasionally misread a profile.
  • Shifting cycles: application volumes and acceptance rates change, and the 2026 entry cycle uses 2025 values.
  • Round effects: Round 1 includes early-action plans at some schools, so its effect is not purely about timing.

Reproduce it

pip install scikit-learn shap pandas scipy
# 1) collect tracker pages (pipeline/collect_example.py uses Perplexity's pplx_sdk content API)
python pipeline/parse.py          # -> rows.json (structured fields only)
python pipeline/build_ref.py      # -> school_ref.json from P&Q tables
python pipeline/train.py          # -> model.json, evaluation, coefficients, SHAP
python pipeline/gen_schools.py    # -> data/schools.json (tuition and aid sources)
python pipeline/export.py         # -> data/model.json for the site
python pipeline/add_stevens.py    # -> adds Stevens (pooled model, no retraining) to data/*.json
